# MovSP 1.0.10

**修复：关闭播放页面后，NAS 仍在持续读盘。**

## 问题

在局域网设备上播放视频，关掉网页后 NAS 的磁盘读取还在继续，直到整部片子被读完。

两个原因叠加：

1. **停止请求找不到对应的流**：流注册时用番号当标识，而停止接口用影片 ID 去找，两者不相等，叫停永远失败
2. **前端只发了停止请求，没断开视频连接**：浏览器还握着 `<video>` 的流，服务端自然继续读盘

## 修复

- 流的标识统一用影片 ID，与停止接口一致
- 关闭页面时同时清空 `<video>` 的 `src` 并 `load()`，让浏览器真正断开连接

## 影响

关闭页面、切换影片、关闭播放器这几种情况现在都会立即停止读盘，不用再等浏览器自己超时。

## 验证

| 检查 | 结果 |
|---|---|
| 停止请求能叫停流 | ✅ `stopped_local: true` |
| 番号作为旧标识时 | 复现了停不掉的问题 |
| 回归测试 | 新增 3 项，锁死 key 一致性 |
