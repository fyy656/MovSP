# MovSP 1.0.7

**修复：换了影片之后，封面还是旧的。**

## 问题

在资料页把 TMDb ID 从一部作品改成另一部（例如《凡人修仙传》真人版 → 动漫版），NFO 更新了，但海报和背景图还是上一部的。

原因：图片的规则是「目录里已有 poster.jpg 就不再下载」，而判断是否覆盖时只看季号，没看片子的 ID 变没变。

## 修复

现在以下情况会重新下载封面：

- **TMDb / IMDb ID 变了**（换了一部作品）
- **库里原本没有 ID、这次显式指定了**（对应「清空输入」后重填再刮）
- 剧集季号变了（原有逻辑）

同一部作品重复刮削仍会复用已有图片，不会每次重下。

## 使用提示

想换版本时两种做法都可以：

1. 点「刮削」→ 在候选里选另一部
2. 点「清空输入」→ 填新的 TMDb ID（或只填剧名）→ 点「保存并刮削」

两种方式都会正确替换封面。
