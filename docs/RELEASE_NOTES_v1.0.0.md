# MovSP 1.0.0

首个正式版本。MovSP 从 JavSP-Web-Next 演进而来，不再只是 JavSP 的网页界面，而是覆盖媒体库完整链路的独立项目。

## 这是什么

一个 NAS 媒体库：索引磁盘、刮削资料、整理文件、浏览播放。

核心区别是**同时支持两条刮削路径**，而不是只服务 JAV：

| | JAV | 电影 / 剧集 |
|---|---|---|
| 识别依据 | 番号 | 片名或 TMDb / IMDb ID |
| 刮削来源 | JavSP 引擎 + 多个资料站 | TMDb API |
| 整理与裁剪 | 支持 | 不做 |
| 配置界面 | 完整 JavSP 选项 | 只显示真正生效的项 |

路径由**预设类型**自动决定，不需要（也无法）手动切换。

## 如何选择

| 你的需求 | 用哪个 |
|---|---|
| 管理 JAV，需要番号识别、分类、裁剪、文件整理 | [JavSP-Web-Next](https://github.com/fyy656/JavSP-Web-Next) |
| 管理 JAV **和**普通影视，统一界面 | **MovSP**（本仓库） |

MovSP 完整保留了 JAV 能力，同时增加了电影/剧集支持。如果你只管理 JAV，两者都可以；如果需要混合媒体库，MovSP 是唯一选择。

## 新功能

### 影片详情页

点开影片先看到大图，而不是一堆输入框：

- 超大横版大图，hover 显示播放按钮
- 信息表：番号 / 发行日期 / 时长 / 片商 / 导演 / TMDb / IMDb
- 底部**图片墙**：竖版海报、横版图、剧照全部列出，点击全屏查看
- 演员、片商可点击，直接跳到同类作品
- 「编辑资料」独立成页，只负责编辑与刮削

JAV 与普通电影共用同一套详情页；剧集与分集仍直接进入编辑。

### 剧集季编号

一季一个目录时，TMDb 一个剧 ID 含全部季，不指定就只会默认取第 1 季——这是多季剧刮错资料的根因。

现在在资料页填写**季编号**即可精确获取：

```
季编号 [5]  →  爱情公寓 第 5 季 / 2020-01-12 / 第五季专属简介与海报
```

分集剧照同时下载为 `<视频名>-thumb.jpg`，Emby / Jellyfin 可识别。

### 刮削器积木化

- 后台定义 21 个刮削器模块及其能力，前端按需勾选
- 影视预设自动隐藏 8 个 JAV 专用选项（番号爬虫列表、JavDB 封面策略、FC2 镜像、深度抓取等），避免误设

### 刮削可靠性

- 图片按 TMDb 支持的尺寸下载（`w500` / `w1280` / `w780`）并自动重试，大幅减少「刮削成功但没图」
- 预设可勾选必须取得的资料，未取到会在任务上标出缺失项
- 任务名显示剧名而非集号
- 下载失败原因直接显示在界面，不用翻日志

### 媒体库体验

- 海报支持竖版 2:3 / 横版 16:9 切换，四档尺寸
- 卡片边框与 hover 反馈
- 分类与剧集返回支持**智能返回上一页**（恢复库、筛选、搜索词、分页与滚动位置）

## 重要变更

### 环境变量改名（向后兼容）

`JAVSP_WEB_*` → `MOVSP_*`

**旧变量名仍然生效**，用原有配置启动不会丢数据。建议之后逐步换成新名。

### 项目结构

| | 之前 | 现在 |
|---|---|---|
| 包目录 | `javsp_web/` | `movsp/` |
| 打包产物 | `JavSP-Web-Next.exe` | `MovSP.exe` |
| Docker 镜像 | `javsp-web` | `movsp` |
| 版本号 | 2.3.2 | **1.0.0**（新项目起点） |

### 保留不变

- `vendor/JavSP/` 上游引擎名与许可证
- 浏览器 localStorage 键 `javsp-web.*`（改动会让现有用户设置全部丢失）
- 上游项目的来源、署名与许可证声明

## 安装

### Windows

下载 `MovSP.exe`，双击运行，浏览器打开 `http://127.0.0.1:8090/login`。

首次账号密码均为 `admin`，登录后立即在「系统设置 → 用户管理」修改。

### Docker

```yaml
services:
  movsp:
    image: ghcr.io/fyy656/movsp:latest
    container_name: movsp
    restart: unless-stopped
    ports:
      - "8090:8090"
    environment:
      MOVSP_HOST: 0.0.0.0
      MOVSP_PORT: 8090
      MOVSP_TIMEZONE: Asia/Shanghai
      TZ: Asia/Shanghai
    volumes:
      - ./data:/app/data
      - /你的影片目录:/media
```

## 已知限制

- 剧集季编号需手动填写（不同剧的目录结构差异太大，自动推断不可靠）
- 图片下载依赖 TMDb 图床，若网络不可达需自备镜像；失败时任务会明确提示
- 电影/剧集目前不做文件整理与封面裁剪，这两项仅 JAV 路径支持
