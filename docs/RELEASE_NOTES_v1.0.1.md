# MovSP 1.0.1

未刮削影片的封面优化，以及两个播放/布局修复。

## 新增

**视频预览帧**：没刮到海报的影片，卡片和详情页显示视频画面，不再是空白。

- 缩略图保存在 `data/thumbnails/`，不写进影片目录，不影响刮削与 Emby
- 需要 ffmpeg（Docker 镜像已内置）；没有时自动退回文字占位
- 工具栏新增「预览图」开关，可随时关闭

## 修复

- 详情页图片墙被压成一列窄条、需横向拖动
- 剧集切下一集时画面消失、只剩声音

---

安装方式不变，详见 [README](https://github.com/fyy656/MovSP#快速开始)。
