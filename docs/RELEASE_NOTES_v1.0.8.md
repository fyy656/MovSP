# MovSP 1.0.8

**修复：剧集的「最小匹配文件大小」几乎不起作用。**

## 问题

预设里填了 200MiB，电影会被正确过滤，但剧集实际上只按 1MiB 判断——填多少都差不多。

原因是代码里对剧集加了一个封顶：`min(预设值, 1MiB)`。本意是防止把番剧整部过滤光，但结果是这个设置对剧集形同虚设。

## 修复

现在电影与剧集完全一致，都按预设值过滤。

**注意**：剧集是按**单集**大小判断的。动漫一集通常 100~300MB，如果你的预设阈值是按整部影片设的（如 200MiB），可能会把剧集过滤掉。界面上已加提示。

## 顺带

- 扫描器页签与「最小匹配文件大小」的说明补充了剧集按单集判断的提醒

## 验证

| 检查 | 结果 |
|---|---|
| 30MB 电影 + 80MB 电影（阈值 50MiB） | 只收 80MB |
| 30MB 单集 + 80MB 单集（阈值 50MiB） | 只收 80MB |
| 10MB 单集（阈值 50MiB） | 被过滤（旧版会保留） |
