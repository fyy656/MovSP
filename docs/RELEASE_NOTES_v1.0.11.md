# MovSP 1.0.11

**新增：剧集分季封面。**

## 问题

TMDb 每季都有独立海报，但刮削时从来没下载过——所有季在媒体库里共用剧集封面，看起来一模一样。

## 修复

刮削某一季时会把该季海报落盘：

| 目录结构 | 保存位置 |
|---|---|
| `Season 1/` 这类季子目录 | `Season N/poster.jpg` |
| 一季一个顶层目录 | `seasonNN-poster.jpg` |

单目录多季时用带季号的名字，各季不会互相覆盖。

## 顺带

- 多季分目录时剧集根目录往往没有海报，现在会回退用第一季的季海报当剧集封面，不再是一片空白

## 使用提示

**已有的剧集需要重新刮削**（在资料页填上对应的季编号）才会补上季海报，旧封面不会自动替换。

## 验证

| 检查 | 结果 |
|---|---|
| 单元测试 | 747 项通过 |
| 季海报落盘（两种结构） | ✅ |
| 剧集封面回退 | ✅ |
